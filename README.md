# Shreyansh Portfolio

A cinematic student portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, Three.js, React Three Fiber, Lenis, and a shadcn-inspired UI system.

## Run locally

```bash
npm install
npm run dev
```

## Environment

Create `.env.local` with:

```bash
NEXT_PUBLIC_GITHUB_USERNAME=Shreyansh11234
```
